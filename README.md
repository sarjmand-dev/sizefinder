# سایزیاب لاورز

اپ آنلاین پیشنهاد سوتین و ست بر اساس دور زیر سینه و دور روی سینه، با لینک خرید، قیمت و موجودی محصولات lovewearz.ir.

## فایل‌ها

| فایل | کار |
|---|---|
| `index.html` | خود اپ (برای مشتری‌ها) |
| `products.json` | محصولات، جدول سایز، قیمت و موجودی (خودکار ساخته می‌شود؛ دستی ویرایش نکنید) |
| `overrides.json` | اصلاح دستی جدول یک محصول یا مخفی کردن آن (اختیاری) |
| `admin.html` | صفحه‌ی مدیریت: وضعیت داده‌ها، مشکلات و دکمه‌ی به‌روزرسانی دستی |
| `scraper/lw-scraper.js` | ابزاری که سایت را می‌خواند |
| `scraper/run.mjs` و `.github/workflows/update.yml` | به‌روزرسانی خودکار روزانه |
| `update-report.md` | گزارش آخرین به‌روزرسانی (خودکار ساخته می‌شود) |
| `thumbs/` | عکس‌های کوچک محصولات (خودکار ساخته می‌شود) |
| `assets/` | لوگو، نماد و آیکون سایت (از برند بوک؛ می‌توانید با فایل اصلی لوگو جایگزین کنید) |
| `fonts/` | (اختیاری) فایل‌های فونت «پیدا»: `Peyda-Regular.woff2`، `Peyda-SemiBold.woff2`، `Peyda-Bold.woff2` |

## راه‌اندازی روی GitHub Pages (رایگان، یک‌بار برای همیشه)

1. در github.com یک حساب بسازید (اگر ندارید) و یک مخزن **Public** جدید بسازید، مثلاً `sizefinder`.
2. در صفحه‌ی مخزن: **Add file ← Upload files**، همه‌ی محتویات این پوشه را (با پوشه‌های `scraper` و `.github`) بکشید و رها کنید و **Commit** بزنید.
   - نکته: پوشه‌ی `.github` در بعضی سیستم‌ها مخفی است؛ مطمئن شوید آپلود شده. اگر نشد، در GitHub یک فایل جدید با نام دقیق `.github/workflows/update.yml` بسازید و محتوای همین فایل را در آن بچسبانید.
3. **Settings ← Pages** ← در بخش Source گزینه‌ی `Deploy from a branch`، شاخه‌ی `main` و پوشه‌ی `/ (root)` ← **Save**.
4. **Settings ← Actions ← General** ← در Workflow permissions گزینه‌ی **Read and write permissions** ← Save.
5. چند دقیقه بعد اپ در این آدرس آماده است: `https://<نام‌کاربری>.github.io/sizefinder/`
6. یک بار به‌روزرسانی را دستی اجرا کنید: **Actions ← به‌روزرسانی محصولات سایزیاب ← Run workflow**. اگر سبز شد، از این به بعد هر روز ساعت ۴ صبح خودکار اجرا می‌شود.

### دامنه‌ی اختصاصی (پیشنهادی)
برای آدرسی مثل `size.lovewearz.ir`: در پنل DNS دامنه یک رکورد `CNAME` با نام `size` و مقدار `<نام‌کاربری>.github.io` بسازید، سپس در **Settings ← Pages ← Custom domain** همان آدرس را وارد کنید و تیک **Enforce HTTPS** را بزنید.

## استفاده در پلتفرم‌های مختلف

- **اینستاگرام / تلگرام / واتساپ / پیامک:** لینک اپ را در بیو، استوری، پیام سنجاق‌شده یا کپشن بگذارید.
- **لینک با اندازه‌ی آماده:** `...?u=75&o=88` اپ را با همین اندازه‌ها باز می‌کند (برای پاسخ دادن به دایرکت‌ها عالی است).
- **داخل سایت خودتان یا هر سایت دیگر:**
  ```html
  <iframe src="https://<نام‌کاربری>.github.io/sizefinder/" style="width:100%;height:1400px;border:0" loading="lazy" title="سایزیاب لاورز"></iframe>
  ```
- همه‌ی لینک‌های خرید برچسب `utm_source=sizefinder` دارند تا در آمار سایت ببینید چند فروش از سایزیاب آمده است.

## به‌روزرسانی موجودی، قیمت و مدل‌های جدید

- **خودکار:** هر روز. برای فوری: **Actions ← Run workflow**.
- **محصول جدید:** فقط کافی است در توضیحات صفحه‌ی محصول جدول سایز با ستون‌های همیشگی باشد
  (سایز روی محصول · دور زیر سینه · دور روی سینه · کاپ · سایز ایرانی). خودش اضافه می‌شود.
- **ناموجود شدن / تغییر قیمت:** از روی رنگ‌ها و سایزهای خود سایت خوانده می‌شود؛ کاری لازم نیست.
- **مشکل در جدول یک محصول:** در `admin.html` یا `update-report.md` نمایش داده می‌شود. بهتر است جدول را در خود سایت درست کنید؛
  اگر نمی‌خواهید، در `overrides.json` جدول درست را بنویسید یا با `"hidden": true` محصول را از اپ مخفی کنید.
- **اگر Action به سایت دسترسی نداشت** (مثلاً اگر سرور سایت آی‌پی‌های خارج از ایران را ببندد، اجرا قرمز می‌شود):
  از روش دستی صفحه‌ی `admin.html` استفاده کنید — یک بوکمارک که روی lovewearz.ir کلیک می‌کنید و `products.json` تازه را
  دانلود می‌کند؛ بعد آن را در GitHub آپلود کنید.

## تنظیمات قابل تغییر (بالای اسکریپت `index.html`)

- `nearLimit`: حداکثر چند سانت فاصله از جدول هنوز «نزدیک به اندازه» حساب شود (پیش‌فرض ۲).
- شماره‌ی تماس و متن‌ها مستقیماً در `index.html` هستند.

## تغییر دامنه (lovewearz.com ← lovewearz.ir)

- اپ و به‌روزرسان روی `lovewearz.ir` تنظیم شده‌اند. آدرس سایت در یک جا تعریف شده: `CONFIG.site` در `index.html` و `LW_SITE` در `scraper/run.mjs`.
- لینک‌های قدیمی `.com` در داده‌ها خودکار به دامنه‌ی فعلی تبدیل می‌شوند.
- پیشنهاد مهم: روی `lovewearz.com` یک ریدایرکت دائمی (301) به `lovewearz.ir` با گواهی SSL معتبر بگذارید تا لینک‌های قدیمی (اینستاگرام، گوگل، مشتریان قبلی) از کار نیفتند.

## عکس محصولات

به‌روزرسانی خودکار، از هر محصول یک عکس کوچک (حدود ۱۰ کیلوبایت) در پوشه‌ی `thumbs` ذخیره می‌کند. اپ اول همین عکس را نشان می‌دهد؛
اگر نبود، عکس اصلی سایت را؛ و اگر آن هم بارگذاری نشد، نماد لاورز را. پس نمایش عکس‌ها به در دسترس بودن لحظه‌ای سایت وابسته نیست.
