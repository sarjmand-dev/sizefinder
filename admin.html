روش ۱ — خودکار (پیشنهادی)

اگر سایزیاب روی GitHub Pages است، هر روز ساعت ۴ صبح خودش محصولات، قیمت‌ها و موجودی را از سایت می‌خواند. برای به‌روزرسانی فوری: در مخزن GitHub به تب Actions بروید، به‌روزرسانی محصولات سایزیاب را انتخاب کنید و Run workflow را بزنید. حدود ۵ دقیقه بعد سایزیاب به‌روز است.

گزارش آخرین اجرا (محصولاتی که جدولشان پیدا نشد یا خوانا نبود) در فایل update-report.md همان مخزن است.

  1. این دکمه را با ماوس بکشید و در نوار بوکمارک مرورگر رها کنید (یک بار برای همیشه):
    به‌روزرسانی سایزیاب
  2. به lovewearz.com بروید و روی همان بوکمارک کلیک کنید.
  3. صبر کنید تا پیام «تمام شد» بیاید (حدود ۳ دقیقه). فایل products.json دانلود می‌شود.
  4. این فایل را به جای products.json قبلی در محل میزبانی سایزیاب آپلود کنید (در GitHub: Add file ← Upload files).

محصول جدید اضافه کردید؟

    
کافی است در توضیحات صفحه‌ی محصول، جدول سایز با همان ستون‌های همیشگی باشد:
      سایز روی محصول · دور زیر سینه · دور روی سینه · کاپ · سایز ایرانی. بازه‌ها را مثل «۷۵تا ۷۸» یا «۸۰/۵تا ۸۳» بنویسید.
      در به‌روزرسانی بعدی، محصول خودش به سایزیاب اضافه می‌شود و موجودی هر رنگ و سایز هم از سایت خوانده می‌شود.

    
برای اصلاح جدول یک محصول بدون دست زدن به سایت، یا مخفی کردن یک محصول از سایزیاب، از فایل overrides.json استفاده کنید.
